# Long/cash deepening — predeclaration

This experiment deepens both promising tracks while preserving the requested
long/cash architecture. The BTC/ETH extension tests slow-signal voting,
volatility scaling and optional drawdown brakes. The ETF extension keeps the
locked rotation signal and tests whether its unused drawdown capacity can be
deployed robustly.

The machine-readable protocol fixes both grids, partitions, costs, selection
rules and robustness tests before evaluation. The same historical partitions
were already inspected in prior work, so neither extension receives a new
holdout claim. Selection artifacts must be committed before the diagnostic
evaluation is opened.

The running BTC/ETH forward account remains frozen. No result from this work can
rewrite, reset, merge with or activate that account, and no broker order is in
scope.
